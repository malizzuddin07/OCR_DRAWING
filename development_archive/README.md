# Development Archive

This folder contains old debugging, test-output, YOLO-run, and earlier archive
folders that are not required to run the current OCR web application.

They were consolidated here on 2026-07-23 to keep the project root clear.
Nothing in `legacy_before_20260723` is approved training truth or an active
production model.

Do not use these files as golden data. The active reviewed references remain
under `golden_tests`.
